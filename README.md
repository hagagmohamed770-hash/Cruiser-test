# مدير الاستثمار العقاري - النسخة النهائية

تطبيق شامل لإدارة الاستثمارات العقارية والعقود والأقساط والشركاء والخزينة.

## 📋 المميزات الرئيسية

### 🏢 إدارة العقارات
- إدارة الوحدات العقارية مع التفاصيل الكاملة
- تتبع حالة الوحدات (متاحة، مؤجرة، مباعة)
- ربط الوحدات بالشركاء مع نسب الملكية
- إدارة تفاصيل العمارات والأدوار

### 👥 إدارة العملاء والشركاء
- قاعدة بيانات شاملة للعملاء
- إدارة الشركاء ومجموعات الشركاء
- تتبع ديون الشركاء والمدفوعات
- نظام عمولات للسماسرة

### 📄 إدارة العقود والأقساط
- إنشاء وإدارة عقود الإيجار والبيع
- نظام أقساط مرن مع تتبع المدفوعات
- تنبيهات الأقساط المستحقة والمتأخرة
- طباعة العقود والتقارير

### 💰 إدارة الخزينة
- إدارة خزائن متعددة
- تتبع المعاملات المالية
- نظام سندات شامل
- تقارير التدفقات النقدية

### 📊 التقارير والتحليلات
- لوحة تحكم تفاعلية
- تقارير شاملة قابلة للطباعة
- تصدير البيانات بصيغة CSV/Excel
- رسوم بيانية وإحصائيات

### 🔒 الأمان والنسخ الاحتياطية
- نظام قفل بكلمة مرور
- نسخ احتياطية تلقائية
- سجل التغييرات والمراجعة
- استيراد/تصدير البيانات

## 🚀 التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Database**: IndexedDB (محلي)
- **PWA**: Service Worker, Manifest
- **Libraries**: HTMX, Chart.js, XLSX
- **UI/UX**: تصميم متجاوب، دعم RTL

## 🛠️ التثبيت والتشغيل

### المتطلبات
- متصفح ويب حديث يدعم IndexedDB
- خادم ويب محلي (اختياري)

### خطوات التثبيت

1. **تحميل المشروع**
   ```bash
   git clone [repository-url]
   cd estate-management-app
   ```

2. **تشغيل التطبيق**
   - افتح `index.html` في المتصفح مباشرة
   - أو استخدم خادم محلي:
   ```bash
   # باستخدام Python
   python -m http.server 8000
   
   # باستخدام Node.js
   npx serve .
   
   # باستخدام PHP
   php -S localhost:8000
   ```

3. **الوصول للتطبيق**
   - افتح المتصفح واذهب إلى `http://localhost:8000`

## 📖 دليل الاستخدام

### البدء السريع

1. **إعداد الخزنة الرئيسية**
   - سيتم إنشاء خزنة رئيسية تلقائياً
   - يمكن إضافة خزائن إضافية من قسم "الخزينة"

2. **إضافة الوحدات العقارية**
   - اذهب إلى قسم "الوحدات"
   - أضف تفاصيل الوحدة (الاسم، الدور، العمارة)
   - حدد الشركاء ونسب الملكية

3. **إضافة العملاء**
   - اذهب إلى قسم "العملاء"
   - أضف بيانات العميل الكاملة
   - يمكن البحث والفرز في قائمة العملاء

4. **إنشاء العقود**
   - اذهب إلى قسم "العقود"
   - اختر الوحدة والعميل
   - حدد شروط العقد والأقساط

### الميزات المتقدمة

#### نظام التراجع والتقدم
- استخدم أزرار "تراجع" و"تقدم" في الشريط العلوي
- اختصارات لوحة المفاتيح: `Ctrl+Z` للتراجع، `Ctrl+Y` للتقدم

#### البحث والفرز
- جميع الجداول تدعم البحث والفرز
- انقر على رؤوس الأعمدة للفرز
- استخدم حقل البحث للبحث السريع

#### التصدير والطباعة
- تصدير البيانات بصيغة CSV
- طباعة التقارير بصيغة PDF
- دعم الطباعة المباشرة

#### النسخ الاحتياطية
- تصدير جميع البيانات
- استيراد البيانات من ملفات النسخ الاحتياطية
- حفظ تلقائي في IndexedDB

## 🐛 استكشاف الأخطاء

### مشاكل شائعة

1. **التطبيق لا يعمل**
   - تأكد من استخدام متصفح حديث
   - تحقق من تفعيل JavaScript
   - امسح ذاكرة التخزين المؤقت

2. **البيانات لا تُحفظ**
   - تحقق من مساحة التخزين المتاحة
   - تأكد من تفعيل IndexedDB في المتصفح

3. **مشاكل في الطباعة**
   - تأكد من السماح بالنوافذ المنبثقة
   - استخدم متصفح يدعم الطباعة

### سجلات الأخطاء
- افتح أدوات المطور (F12)
- راجع علامة التبويب Console للأخطاء
- سجل الأخطاء في قسم "سجل التغييرات"
